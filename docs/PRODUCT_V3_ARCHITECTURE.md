## 1. North star

**Карманный тренажёр + AI-наставник**, не сериал в чате.

| Столп | Роль |
|-------|------|
| **Слова** | Главный магнит: банк A1–C1, прогресс, повтор |
| **Правила** | Банк по уровням (как слова) — **основной paywall на free** |
| **План дня** | Слова + правило + слушание + диалог AI |
| **Наставник** | Спирит, голос по минутам |
| **Диагностика** | Тест → слабые места (лексика, правила) |

**Emma / эпизоды:** убрать из бота (код можно оставить в репозитории как архив, в UX не показывать).

## 6. Тарифы v3 — **только 3: Free · Basic · Pro**

> Active **убираем**. Экономика: **`docs/TARIFFS_ECONOMICS_V3.md`**

### 🆓 Free

| ✅ | 🔒 |
|----|-----|
| Слова — весь банк, текст, 🔊, SRS | 🎙️ говорить |
| Диагностика | План дня (после trial) |
| **3 правила** | остальные правила |
| Наставник текст, **20 сообщ./мес** | голос |

### 🎁 Trial — 3 дня (как Basic)

### 💳 Basic — **349 ₽** · **60 мин 🎙️/мес** · 500 сообщ.

«~**2 минуты в день**» — хватит на спокойную ежедневную практику.

### 💳 Pro — **990 ₽** · **240 мин 🎙️/мес** · 1200 сообщ.

«~**8 минут в день**» — говоришь каждый день без стресса.

### Paywall-текст

> Слова бесплатно. **349 ₽** — программа + голос понемногу. **990 ₽** — много говоришь.
