# ЮKassa — что отправить менеджеру

Когда магазин просит «подробности о Telegram-боте» и скриншоты с **ценами и описанием услуг**, приложите материалы ниже.

---

## 1. Текст для поля «Ваше сообщение»

```
English Mentor Bot — Telegram-бот для изучения английского (RU аудитория).

Продукт: подписка на обучающую программу (уроки-истории, словарь, грамматика, AI-наставник).

Бесплатно для пользователя:
• диагностика уровня;
• эпизоды 1–3 сериала (чтение + озвучка 🔊);
• словарь, карта правил, тренировки текстом.

Платные тарифы (30 дней, без автопродления):
• Basic — 590 ₽/мес (~60 мин голоса с наставником);
• Active — 990 ₽/мес (~180 мин голоса);
• Pro — 1 990 ₽/мес (~450 мин голоса);
• Докупка +100 мин голоса — 290 ₽ (при активной подписке).

Оплата в боте: кнопка «⭐️ Подписка» → выбор тарифа → Telegram Payments (ЮKassa).
```

---

## 2. Скриншоты (5 файлов максимум)

Сделайте **полноэкранные** скрины в Telegram (тёмная/светлая тема — не важно):

| № | Что снять | Зачем |
|---|-----------|--------|
| 1 | `/start` или главное меню с названием бота | Имя бота видно |
| 2 | Экран «⭐️ Подписка» с **тремя тарифами и ценами** | Карточки услуг + цены |
| 3 | Урок / план дня (контент программы) | Что покупает пользователь |
| 4 | Профиль (`👤 Профиль`) — уровень, подписка | Персонализация |
| 5 | (опционально) Условия / описание тарифа из бота | Доп. описание |

**Как получить экран тарифов:** в боте нажмите **⭐️ Подписка** (или дойдите до paywall после эпизода 4).

---

## 3. После одобления ЮKassa

1. @BotFather → Payments → подключить провайдер → скопировать `TELEGRAM_PAYMENT_PROVIDER_TOKEN`.
2. На сервере в `.env`:
   ```
   PAYMENT_MODE=live
   TELEGRAM_PAYMENT_PROVIDER_TOKEN=...
   YOOKASSA_SHOP_ID=...
   YOOKASSA_SECRET_KEY=...
   ```
3. Перезапуск: `systemctl restart english-mentor-bot`
4. Тестовая покупка на минимальном тарифе Basic (590 ₽).

Пока `PAYMENT_MODE=mock` — оплата симулируется (для разработки).

## 4. Где смотреть, кто оплатил

| Способ | Команда / URL |
|--------|----------------|
| Django Admin | `/admin/` → Users → User profiles (колонки «Тариф», «Подписка до») |
| Платежи | `/admin/billing_app/payment/` |
| SSH | `python manage.py list_user_billing` |
| Только платные | `python manage.py list_user_billing --paid-only` |

## 5. Лендинг и Instagram

Лендинг делается отдельно (Tilda / Readymag / др.). На лендинге укажите:

- ссылку на бота `t.me/YourBotUsername`;
- те же 3 тарифа и цены, что в боте;
- «2 дня полного доступа» + «бесплатно навсегда: эпизоды 1–3».

Не обещайте на лендинге функции, которых нет в боте.
